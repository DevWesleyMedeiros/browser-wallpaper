# Tela de Descanso - Bouncing Balls

Um projeto prático e visualmente agradável de bolas coloridas que quicam na tela, perfeito para usar como papel de parede ou tela de descanso!

## Stack Utilizada
- **HTML5** - Estrutura da página
- **CSS3** - Estilização e animações
- **JavaScript (ES6+)** - Lógica de programação orientada a objetos

## Funcionalidades
- Adicionar múltiplas bolas coloridas de uma vez
- Controlar a velocidade das bolas
- Definir tamanho mínimo e máximo das bolas
- Opção de mostrar trilhas das bolas
- Painel de controles ocultável (perfeito para usar como wallpaper)
- Animações suaves e design moderno

## O que pode ser estudado neste projeto?
1. **Programação Orientada a Objetos (POO)** - Implementação da classe `Bola`
2. **Manipulação do DOM** - Criação e remoção de elementos dinamicamente
3. **requestAnimationFrame** - Animações performáticas no navegador
4. **CSS Animations e Transitions** - Efeitos visuais suaves
5. **Event Listeners** - Interação com o usuário
6. **Resposividade** - Adaptação a diferentes tamanhos de tela
7. **Gerenciamento de estado** - Controle de array de objetos

## Como clonar e usar?

1. **Clone o repositório**
   ```bash
   git clone https://github.com/wesleymartins15/projeto-pratico-com-classes.git
   cd projeto-pratico-com-classes
   ```

2. **Abra o arquivo**
   Basta abrir o arquivo `index.html` em qualquer navegador moderno!

## Como usar como wallpaper?
1. Abra o arquivo `index.html` no navegador
2. Clique no botão ⚙️ para ocultar os controles
3. Coloque o navegador em tela cheia (F11)
4. Adicione as bolas e aproveite!
